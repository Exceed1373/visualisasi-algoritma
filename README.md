# VisuAlgo PTIK
Website pembelajaran interaktif visualisasi algoritma Sorting dan Searching (HTML, CSS, Vanilla JS, tanpa framework/database).

## Struktur
```
index.html  sorting.html  searching.html  petunjuk.html
css/style.css
js/main.js      (navigasi + pemilih algoritma, dipakai bersama)
js/sorting.js   js/searching.js
.nojekyll
```

## Menjalankan lokal
Buka `index.html` di peramban. Semua tautan memakai path relatif, jadi aman untuk GitHub Pages.

## Deploy ke GitHub Pages
1. Buat repository baru, upload seluruh isi folder ini ke branch `main`.
2. Settings > Pages > Source: *Deploy from a branch* > `main` / `(root)` > Save.
3. Situs aktif di `https://<username>.github.io/<nama-repo>/`.

## Tahap pengerjaan
1. Struktur, navigasi, halaman, dan tata letak (selesai).
2. Mesin animasi Sorting (5 algoritma) (selesai).
3. Mesin animasi Searching (selesai).
4. Pengujian, responsivitas, dan perapian.
