Petunjuk penggunaan

  1. Pilih materi (Sorting atau Searching) dan algoritmanya.
  2. Atur data dan kecepatan animasi.
  3. Tekan Mulai atau Langkah.
  4. Baca penjelasan langkah dan arti warna.

Arti warna

  • Belum diproses
  • Sedang dibandingkan
  • Ditukar / posisi tengah (mid) / pivot
  • Terurut / ditemukan

Fungsi tombol

Mulai
Menjalankan animasi otomatis sampai selesai.
Jeda
Menghentikan animasi sementara.
Langkah
Menjalankan satu tahap saja.
Reset
Memuat ulang data dari awal.
Ganti algoritma
Kembali ke daftar algoritma.

Persyaratan peramban

Gunakan Chrome, Firefox, Edge, atau Safari versi terbaru dengan JavaScript aktif. Tidak perlu instalasi.
